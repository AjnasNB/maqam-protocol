# Build provenance and track correction

This is a new payment application created in this repository on September 12, 2026, during ETHOnline. The user clarified that it should be evaluated as a new application, rather than a feature shipped in the existing Maqam repository.

The initial Continuity selection was based on the existing Maqam product context. Inspection shows the older code is installed only as the pinned public MIT npm package `maqam@0.3.3`. The Solidity contracts, browser payment interface, Graph integration, server adapters, assets, tests and deployment scripts were created during this event. The new project does not copy the earlier application's source, designs or assets into this repository. The related Maqam name and conceptual background are disclosed; the generic library itself is not claimed as event work.

The published ETHOnline rules allow public libraries and boilerplate in From Scratch entries. On that basis we changed the project to **Building from Scratch**, while retaining disclosure of the earlier library and all AI assistance. This is our documented interpretation, not a statement of organizer approval. The incremental git history preserves the initial classification and subsequent correction.

Source: [ETHOnline event rules](https://ethglobal.com/events/ethonline2026/info/start), [submission requirements](https://ethglobal.com/events/ethonline2026/info/details).

AI-assisted implementation is disclosed in `AI-ASSISTANCE.md`. Participant direction includes the exact-authorization problem, testnet-only constraint, live Graph integration, sponsor priorities and requirement for real Chrome capture. Hands-on testing and human narration remain recorded only when actually completed.
